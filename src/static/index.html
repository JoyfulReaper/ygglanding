About

Hello, my name is Kyle Givler. This is my little corner of Yggdrasil.

I use this network for software, experiments, smolweb stuff, old protocols, and whatever other weird services I feel like putting online.

Some services run directly on Clanker, while others are proxied over private links to machines elsewhere on my network.

No ads, no analytics companies, no cookie banners, and no algorithm deciding what you should look at next.

Basic request telemetry is sent to my private Mission Control dashboard, which collects events from my various services.

DNS is provided mostly for convenience and protocol compatibility. Raw Yggdrasil addresses are shown where practical so services can still be reached without it.

More weird little services will probably appear here over time.

    301:762f:80bd:20e1::20
