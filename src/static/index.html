Services

  • Random Steam Game Picker
    https://steam.ygg.kgivler.com/
    Ygg IPv6:
    201:762f:80bd:20e1:20db:1239:19af:f25e
    This service uses HTTPS because the application relies on Secure ASP.NET Core cookies and antiforgery protection. Plain HTTP causes those cookies to be rejected or omitted by the browser.
    The hostname is also required for TLS certificate validation because the certificate is issued for steam.ygg.kgivler.com, not the raw IPv6 address.
    No DNS? Add this to your hosts file:
    201:762f:80bd:20e1:20db:1239:19af:f25e steam.ygg.kgivler.com
  • Random GitHub
    http://git.ygg.kgivler.com/
    Raw Ygg address:
    http://[201:762f:80bd:20e1:20db:1239:19af:f25e]/
    Random repository browsing works over plain HTTP and can be accessed directly by hostname or raw Ygg IPv6.
    The optional "Use your own GitHub token" feature does not work over HTTP because its ASP.NET Core session cookie is marked Secure.
  • kgivler.com
    http://site.ygg.kgivler.com/
    Ygg IPv6:
    201:762f:80bd:20e1:20db:1239:19af:f25e
    This site is hosted on my workstation rather than on the Yggdrasil node itself. Clanker accepts the Ygg request and proxies it over WireGuard to IIS on my workstation.
    The hostname is required because nginx uses it to select the correct virtual host. The raw IPv6 address alone is shared by several HTTP services.
    No DNS? Add this to your hosts file:
    201:762f:80bd:20e1:20db:1239:19af:f25e site.ygg.kgivler.com api.ygg.kgivler.com
    Ygg API:
    http://api.ygg.kgivler.com/api/system/usage
  • HappyGopher
    gopher://gopher.ygg.kgivler.com/
    Raw Ygg address:
    gopher://[201:762f:80bd:20e1:20db:1239:19af:f25e]:70/
    The DNS hostname is recommended because Gopher menu host fields were designed before IPv6 and raw IPv6 literals are not handled consistently by all Gopher clients.

About

These services are reachable through the Yggdrasil network. Some are hosted directly on Clanker, while others are proxied through private links to other machines.

DNS is provided mainly for convenience and protocol compatibility. Where possible, raw Ygg IPv6 addresses are also shown for environments with limited or unavailable DNS.

More weird little services will probably appear here over time.
